# Milestone 4 — pre-plan rulings (answers to the seam report's §5 open questions)

These are the planner's calls on the 30 open questions in `2026-10-24-m4-seam-report.md` §5, made before the M4 plan was written so that every plan draft shares the same design. Technical decisions are delegated to Claude by the design spec §7; the owner approved proceeding with the M4 plan on 2026-10-24. Items the owner may want to overrule are marked **(owner may overrule)**. Execution rulings and deferred items are appended below during execution, in the style of the M1–M3 rulings docs.

## Revive (seam 2)

1. **Downed representation:** a new `RunPhase.downed` case. `World` enters `.downed` instead of `.gameOver` only when revive is permitted (ruling 3) and unused; otherwise it enters `.gameOver` exactly as today, so every existing test and the probe harness are untouched. `tick` is a no-op in `.downed` (the existing `guard phase == .playing`).
2. **Events:** `.hiveDowned` is emitted when entering `.downed`; `.gameOver` is emitted only when entering `.gameOver` (directly, or via `abandonRevive()` from `.downed`). "Exactly one `.gameOver` per run" stays true for every run. A revived hive that dies again goes straight to `.gameOver` (revive is once per run).
3. **How World learns revive is permitted:** a defaulted init parameter `reviveAllowed: Bool = false`, stored as `public private(set) var reviveAllowed` and `public private(set) var reviveUsed = false`. The app passes `true` whenever the ad system is started (consent done). Whether a rewarded ad is actually loaded is checked by the app at the moment of `.downed`; if none is loaded the app calls `world.abandonRevive()` in the same frame, so the player never sees a broken revive prompt. World stays ad-agnostic.
4. **Revive semantics (`public mutating func revive()`):** valid only in `.downed`; sets `hive.hp = 0.5 * hive.stats.maxHP` (set, not add — hp is negative), `reviveUsed = true`, `phase = .playing`; every boss gets `attackCooldown = max(attackCooldown, 1.5)`; every non-boss mob with `position.length < 150` is **displaced** (not removed) to distance `150 + radius` along its current bearing from the hive (rng-free; mobs exactly at the origin use bearing 0). Projectiles, bees, `hive.cooldown`, nectar, `time`, escort timers are untouched. `abandonRevive()`: valid only in `.downed`; sets `.gameOver` and emits `.gameOver`. Both are no-ops (return `[]`) outside `.downed`.
5. **`RunResult.revived`:** added as a defaulted `Bool` (`= false`) mirrored from `world.reviveUsed` by `AppFlow.makeRunResult`. A revived story clear **counts** for `highestClearedLevel` (spec anti-goal: ads accelerate, they never gate). The flag is informational.

## Premium card (seam 4)

6. **Replace, not add:** taking the premium card consumes the pick — the app calls `world.choose(premium)` exactly like a regular card; `choose` keeps accepting any card (no membership check).
7. **Roll ownership:** `World`. New defaulted init parameter `premiumPool: [UpgradeCard] = []`; a second generator `private var premiumRNG: SeededRNG` created at init from `seed ^ 0x9E37_79B9_7F4A_7C15` (nonzero constant, never derived from `rng`). `public private(set) var premiumOffer: UpgradeCard?` is set in the single pick-open path and cleared by `choose`. The main `rng` is never consumed by premium logic.
8. **Locked pool definition:** `UpgradeCatalog.locked(unlockedThrough: level) = all.filter { $0.unlockLevel > level }`, with `poolLevel` exactly as `AppFlow` computes the regular pool (story `id − 1`, endless `highestClearedLevel`). Level 1 therefore offers the four epics, **not** `all − milestone1` (this re-rules the M3 text: offering a plain rare as "premium" would read as a bait). Cost if wrong: none at runtime.
9. **Empty locked pool (poolLevel ≥ 15):** the slot is hidden (`premiumOffer == nil`). "Epic versions of common cards" are deferred to M5 and noted there.
10. **Roll details:** one roll per pick open (each pick in a `pendingPicks` chain rolls independently) with `premiumRNG.unitDouble() < 1.0 / 3.0`; when `premiumPool` is empty no roll is made and `premiumOffer` is `nil`; the draw is `UpgradeCatalog.draw(count: 1, from: premiumPool, rng: &premiumRNG, epicWeight: <same formula as the main draw>)`.
11. **No rewarded ad loaded:** World rolls regardless; the app omits the 4th row when no rewarded ad is ready at overlay-build time. If the ad is cancelled or fails after the row was tapped, the overlay stays up with the same four rows (the offer lives in World) and the row is disabled.

## Interstitials and counters (seam 5)

12. **Decision point:** at the `EndOverlay` button tap (before `flow.startLevel` / `flow.showHome`), never at record time. `GameScene` asks `flow.interstitialPermitted(now:)`; if permitted, `AdManager.showInterstitial(from:onDismiss:)` and the navigation runs in `onDismiss` (also on failure to present).
13. **Which exits are eligible:** CONTINUE, RETRY and HOME on the `EndOverlay` (the run has ended). Pause-RETRY and pause-HOME are **never** eligible (they are quits, not level ends).
14. **Counting:** `GameState.record` increments `levelsEnded` for every newly recorded run (story clear, story loss, endless end, pause-abandon) — idempotent per `runID`. `AdRules.mayShowInterstitial(state, now)` requires `levelsEnded > 3` (the first three run ends of a fresh install are ad-free), `levelsEnded − lastInterstitialAtLevelsEnded ≥ 3`, and `lastRewardedAdAt == nil || now − lastRewardedAdAt ≥ 90` with a clock set backwards (`now < lastRewardedAdAt`) treated as still inside the cooldown.
15. **Pre-M4 saves:** new counters default to 0 / nil; existing (dev) players get the fresh-install grace again. Accepted.
16. **Field names (re-ruling the M2 names):** `levelsEnded: Int`, `lastInterstitialAtLevelsEnded: Int`, `lastRewardedAdAt: Double?`, `consentPrompted: Bool`, `bonusAwardedRunIDs: [UUID]`. Every one is in `CodingKeys`, defaulted in `init()` and the memberwise init, and `decodeIfPresent` in `init(from:)`.
17. **Clock:** `Double` unix seconds (`Date().timeIntervalSince1970`), injected as `now: TimeInterval`; HiveCore never calls `Date()` in game logic.
18. **`currentVersion` stays 1.** All new fields are additive and optional. `save_v1.json` is extended by a sibling fixture `save_v1_m4.json` containing every new field; the decode-missing-field test asserts every new field's default.

## Double coins (seam 3)

19. **Where offered:** when `result.cleared || result.mode == .endless` (the endless end screen is its "level complete"). Not on a story loss. **(owner may overrule — offering it on losses too would raise ad views.)**
20. **`awardBonus(runID:coins:) -> Bool` guards:** `recordedRunIDs.contains(runID)`, `!bonusAwardedRunIDs.contains(runID)`, `coins > 0`; appends to `bonusAwardedRunIDs` trimmed to `runIDHistoryLimit` (20). Bonus = `result.coinsEarned` (already multiplied once in `makeRunResult`; never re-multiplied).

## Consent / ATT (seam 7)

21. **Trigger:** the first recorded story run end of any outcome (`!consentPrompted && levelsEnded >= 1 && result.mode is .story`), evaluated by the app right after `runEnded`, presented on the next run-loop turn after the `EndOverlay` is on screen. One flag `consentPrompted`; UMP keeps its own consent status and re-prompts when required on later launches; ATT is one-shot by iOS.
22. **Ordering / presenter:** UMP `requestConsentInfoUpdate` → `loadAndPresentIfRequired(from:)` → if `ATTrackingManager.trackingAuthorizationStatus == .notDetermined`, `requestTrackingAuthorization` → `MobileAds.shared.start` → preload. The presenter is `RootViewController`, injected into `AppFlow` at `SceneDelegate` as a `UIViewController` reference. Mac verification required; the exact UMP/ATT interplay is checked against current Google docs there.

## AdManager and SDK (seam 8)

23. **App ID:** Google's published **test** App ID in `Info.plist` for M4 (`GADApplicationIdentifier`); real-ID injection through an uncommitted xcconfig is M5 (spec §8). A tiny `AdUnitIDs` loader reads `Hive/Resources/AdConfig.plist` when bundled and falls back to Google's test unit IDs; `#if DEBUG` always uses the test IDs.
24. **SDK majors:** Google Mobile Ads SDK **v12** (Swift-first API: `MobileAds.shared`, `RewardedAd.load(with:request:)`, `present(from:userDidEarnRewardHandler:)`, `InterstitialAd.load(with:request:)`, `FullScreenContentDelegate`) and UMP **v3** (`ConsentInformation.shared`, `ConsentForm.loadAndPresentIfRequired(from:)`). `project.yml` pins both with `exactVersion`, chosen on the Mac in the SDK task (the latest 12.x / 3.x available), because `Package.resolved` is gitignored.
25. **Not-loaded buttons:** hidden (spec). DOUBLE COINS is added to `EndOverlay` only when a rewarded ad is ready; after the reward it stays visible but disabled with the copy "DOUBLED"; the coins label updates to the doubled total. The premium row is omitted when no rewarded ad is ready. The revive overlay is skipped entirely (→ `abandonRevive()`) when none is ready.
26. **Audience:** `MobileAds.shared.requestConfiguration`: `tagForChildDirectedTreatment = false`, `tagForUnderAgeOfConsent = false`, `maxAdContentRating = .teen`; `testDeviceIdentifiers` set only under `#if DEBUG`. All in `AdManager`.
27. **AdManager shape:** `protocol AdProviding` (`isRewardedReady`, `isInterstitialReady`, `showRewarded(from:onReward:onDismiss:)`, `showInterstitial(from:onDismiss:)`, `preload()`, `start(from:completion:)`) owned by `AppFlow`; `AdMobProvider` (real) and `NoAdsProvider` (fake, used until consent and in any build without the SDK). `GameScene`/overlays read availability only through `AppFlow`.

## World split and tests (seam 1, §5 Q27–30)

28. **Access widening:** `private` → `internal` for the members `World+Mechanics.swift` needs (invisible to the app, visible to `@testable` tests). Helpers move; the `tick` step order and floating-point operation order are preserved exactly.
29. **Tests first:** the three missing M3 tests (`testBeeKillAddsNectarAndOpensPick`, `testSplashStillHitsNeighborsWhenShotKills`, `testBeeStingRespectsArmorMinimumOne`) plus a **golden-run pin** (`testGoldenRunUnchanged`: fixed seed, `level_test.json`, 600 ticks at 1/30 s, asserting literal event counts and final hive hp recorded before the split) and a **same-seed determinism test** (`testSameSeedProducesIdenticalEventStream`) land in their own commit before any refactor. The premium task adds `testPremiumPoolDoesNotPerturbMainDraw` (premium pool `[]` vs non-empty → identical `.pickingCards` payloads and event streams).
30. **Probe cadence:** `swift test --skip LevelCurveProbeTests` after every change; `swift test` (default probes, ~90 s) before every commit; `HIVE_FULL_PROBE=1 swift test` once after the World split, once after the premium task, and once at the end of the core tasks. The 14 baseline probe lines in the seam report §3 must be byte-identical after every World-touching task.
