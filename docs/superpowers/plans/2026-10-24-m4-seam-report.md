## 4. Risks ranked (top 10)

1. **RNG drift fails the probes.** Any new `rng.unitDouble()` on the main stream (premium roll, premium draw, knock-back jitter) or a reordering of spawn/escort/draw calls or floating-point ops during the World split shifts every later value; the baseline (§3 #1) has five probed levels exactly at a bound and the greedy L1 probe one unit above its floor. *Mitigation:* second `SeededRNG` built at `World.swift:58` from `seed ^ C` and used only for premium; rng-free revive; before/after the split run `swift test` and `diff` the 14 printed probe lines verbatim (they are in this report); run `HIVE_FULL_PROBE=1` once per World-touching task.
2. **"Exactly one `.gameOver`, phase terminal" vs a downed state.** A `.downed` that World enters by default breaks `WorldCombatTests:55-56/72-73` and `EndlessTests:52-53`, and makes `ProbeHarness:54` spin to `timeCap` counting every run as not cleared. *Mitigation:* revive availability is an injected input defaulting to off, so the headless path still hits `World.swift:220`; a second `.gameOver` after a revived hive dies must not be emitted (emit `.hiveDowned` at HP zero when armed, `.gameOver` only on finalization), or the invariant is redefined explicitly in the plan.
3. **Recording before the revive decision.** `GameScene.swift:235-239` records and pays out on the first terminal frame; a `.downed` arm that records (or a flag-based design that leaves `phase == .gameOver`) banks the run before the player decides, and `lastReportedRunID` then silently drops the finalization record, so a revived-and-cleared run is banked as a loss. *Mitigation:* the downed arm must not record; record once on finalization; add a `recordIfInProgress` arm decision (downed abandoned = loss) and keep `runID` constant across revive.
4. **`RunPhase.pickingCards` payload shape / new unresolved phase.** Appending the premium card to the payload breaks `RunPhaseTests:17` (count 3) and `WorldStartingCardsTests:19` (membership), changes draw count (probe drift) and makes the probes take the locked epic for free (`greedyPriority` ranks `swarm_call`/`queens_wrath` first, `ProbeHarness:66`); changing the associated value breaks 13 binding sites; a new phase the harness cannot resolve collapses every probe. *Mitigation:* `public private(set) var premiumOffer: UpgradeCard?` beside the unchanged payload; no new phase during picks.
5. **GameState Codable pitfalls.** A new stored property left out of the explicit `CodingKeys` compiles and is silently never persisted; a non-defaulted memberwise parameter breaks `GatingTests:13/27`; defaults in `init()` vs `init(from:)` can diverge; a later JSON type change makes `decodeIfPresent` throw → whole save quarantined and coins moved aside; bumping `currentVersion` makes any pre-M4 build quarantine the file and does nothing by itself because `version` round-trips verbatim. *Mitigation:* extend `testSaveRoundTrip` to set every new field; keep `currentVersion = 1`; freeze field types; add a decode-missing-field assertion per new field.
6. **Interstitial on pause-RETRY or over the results card.** `runEnded` has no exit reason and runs inside `update` right before `EndOverlay` appears; deciding/showing there violates "never on pause-RETRY" and covers DOUBLE COINS; a `GameScene` presented under an ad plays waves behind it. *Mitigation:* keep the rule pure in HiveCore (`AdRules`, injected `now`), count inside `record`, decide and present in the EndOverlay CONTINUE/HOME (and RETRY if ruled) closures before `flow.startLevel`/`showHome`; pass an exit reason if `runEnded` is kept as the hook.
7. **Async ad callbacks vs the per-frame overlay loop.** `CardPickOverlay` removes itself and the scene nils `overlay` before applying the pick; `presentOverlayIfNeeded` re-creates the overlay on the next frame when `phase == .pickingCards` (and would re-roll a scene-side premium slot); a rewarded callback arriving after the pick phase ended (pause→RETRY/HOME) makes `choose` a silent no-op (`World.swift:289`). *Mitigation:* an `awaitingAd` state that keeps `overlay` non-nil, the premium roll stored in World per pick, and callbacks that re-check `world.runID`/phase.
8. **EndOverlay is single-shot and built from init-locals.** Wiring DOUBLE COINS into `actions` kills CONTINUE/RETRY/HOME after the reward; the `+N coins` copy cannot be updated; there is no room between the coins label and the first button. *Mitigation:* promote labels to properties, add the button outside `actions`, disable it after the reward, place it first at y −20 (stack ends at −244 at 667 pt).
9. **Revive mob handling has side effects.** Removing non-boss mobs bypasses `.mobKilled`/nectar and, in a fixed level with `allSpawnsIssued` true and no boss, step 12 (`World.swift:278-281`) clears the level on the next tick and `countClearedWave` (`:322`) counts the wave; escorts spawn at 140 pt (inside 150); a parked boss has `attackCooldown ≤ 1.0` right after the fatal hit (`:208`), so a 50-HP base hive vs a bear (40/hit) dies again in ~2 s without the 1.5 s reset; `hitFlash` is not decayed on the fatal tick (cosmetic). *Mitigation:* displace rather than remove (or rule the clear acceptable), set boss `attackCooldown` explicitly, test with `oneBearBossLevel()`.
10. **Toolchain and SDK integration surprises (Mac-only).** `Package.resolved` is gitignored (versions resolve fresh unless pinned in `project.yml`); SDK major decides API names; `-ObjC` required; missing `GADApplicationIdentifier` traps at start; an on-disk `AdConfig.plist` is auto-bundled; the app target has **no tests**, so every placement/timing rule placed in app code is unverifiable here. *Mitigation:* pin exact versions; AdManager behind a protocol with a `NoAdsProvider` fake; DEBUG uses Google test ids regardless of config; keep all rules in HiveCore; order Linux-buildable tasks first (§6).
